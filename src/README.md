# 🚀 Space Blaster

An interactive, browser-based arcade shooter game featuring **real-time hand-tracking** via webcam. Control your spaceship and blast through obstacles using hand gestures powered by MediaPipe!

🔗 **Live Demo:** [https://space-blaster-six.vercel.app/](https://space-blaster-six.vercel.app/)

---

## ✨ Features

- **Gesture Control:** Uses your webcam and MediaPipe Hands to track hand movements in real-time for gameplay interaction.
- **Modern Frontend:** Built with React and Vite for blazing-fast performance and smooth animations.
- **Responsive Design:** Optimized for seamless gameplay directly in modern web browsers.

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, JavaScript / JSX
- **Computer Vision:** Google MediaPipe (Hands & Camera Utils)
- **Styling:** CSS / Tailwind CSS
- **Deployment:** Vercel
